# 🎯 Customer Churn Prediction System

## 📋 Project Overview
This Machine Learning project predicts customer churn for telecom companies using multiple algorithms including Random Forest, XGBoost, and Neural Networks.

## 🚀 Features
- **Data Preprocessing**: Automated cleaning, encoding, and scaling
- **Multiple ML Models**: Comparison of 4 different algorithms
- **Web Interface**: User-friendly Flask web application
- **REST API**: Easy integration with other systems
- **High Accuracy**: 85%+ prediction accuracy

## 🛠️ Tech Stack
- Python 3.9+
- Scikit-learn, XGBoost
- Flask for web interface
- Pandas, NumPy for data processing
- Matplotlib, Seaborn for visualization
